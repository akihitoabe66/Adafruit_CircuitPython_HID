## 1. 誰に、何を届けるか
- **遊ぶ人**: シニア(60代〜)。昔の麻雀を覚えている人も、これから覚える人も。
- **買う人**: シニア本人と、その子の世代(親にプレゼントする人)。
- **約束すること**: 「大きくて見やすい画面で、ゆっくり覚えて、段位が上がっていく」。オフラインで、長く遊べる。
- **遊ぶ場所**: ノートパソコン(Windows 10/11)。インストールしたら、ネット接続なしで遊べる。

## 2. 守ること(操作と見た目)
`DESIGN_SENIOR.md` の7つの原則を引きつぐ。新しい前提で、次を決める。
1. **マウスが基本**。ゲームコントローラーを接続したら、同じことが十字キー+A+Bでできる(`js/pad.js`)。キーボードがなくても、すべて遊べる。
2. **牌も文字も、できるだけ大きく**。基準は1920×1080。ノートPCの1366×768でも、はみ出さない。
   - 本文は、実際の見た目で28px以上。補助の文字も20px以上。
   - 牌は、手牌が画面の下に1列で並び、1枚が指で押せる大きさ(画面の幅の約1/16以上)。
3. **押し間違いを防ぐ**。牌は「1回目で選ぶ(持ち上がる)、2回目で捨てる」。鳴きの確認は大きなボタン。最初の選択は「見送る」。
4. **画面ごとにやることを1つに**。ボタンは、ホームで4つまで。
5. **スクロールなし**。1画面に収める。文字が多いときは、ページ送り。
6. **取り返せない操作は、確認**。「やめる」「リセット」は、赤+⚠。
7. **先生(解説)は、いつでも入り切り**。最初は「つけない」。

## 3. ゲームの中身(土台はPi版のコード)
4人対戦の本格麻雀。CPUは5段階以上の強さ、32人の個性(強さ・打ち方)を持つ。

| 柱 | 内容 | 元になるもの |
|---|---|---|
| 対局(段位戦) | 気軽にループできる。東風戦中心。段位が上がる・下がる | `rank.js`(無段〜九段・名人・永世名人、不調時の救済、自動セーブ) |
| 麻雀クイズ | 何切る・待ち・役・鳴き・安全牌。苦手な種類を多めに出す | `drill.js`・`study.js` |
| 点数計算の勉強 | 役・飜・符・点数。短い読み物+チャレンジ | `learn.js`・`study.js` |
| 先生(サポート) | 対局中に「おすすめ」「危ない牌」を表示。いつでも入り切り | `coach.js`・`ai.js` |
| 振り返り | 間違えた場面をノートに保存し、あとで1問ずつ出す | 「中級を目指す麻雀」の `Mistakes` |
| 毎日1問 | 起動したら「最初に何を切る?」。答えるとスタンプ | 「中級を目指す麻雀」の `Daily` |
| 辞典・ノート | 用語を引ける。用語の読みも大きく | `glossary.js` |

### 「中級」とは何か(プレイヤーに見せる)
- 「中級の目安」を画面に出す。分野ごとに「わかった」の印が付く。
  - 牌効率 / 役づくり / 守備(安全牌) / 鳴き判断 / 点数計算 / 押し引き
- 各分野で10問以上・正解率70%以上で「わかった」。全部そろったら「中級認定」(認定証の絵)。
- 段位(対局)と、中級の目安(勉強)の、2本立て。どちらからも進める。

### 長くループで遊べる仕組み
- 段位が上がると、相手が強くなる(`MJ.effLevel`)。名人の先にも続く。
- 毎日のスタンプ(連続日数)と、ミスノートの復習。
- 32人の雀士を「出会った」順に集める(雀士列伝)。
- 季節や舞台に合わせた背景・BGMの切りかえ(BGMは、作者本人の曲を流用)。

## 6. 技術
- **土台**: Pi版の Web版(`js/`・`index.html`)。Pi専用の部分(`native/`・OLED・ブザー)は使わない。
- **包み方**: Electron(Windows用の `.exe`)。Steam連携は steamworks.js など。Tauri も候補。
- **オフライン**: すべての素材を同梱する。通信なし。セーブは、パソコン内(Steam Cloud は任意)。
- **コントローラー**: Steam Input とブラウザのゲームパッドAPIの両方に対応する。
- **画面**: 1920×1080 を基準に拡大縮小。ノートPCの Windows の拡大設定(125〜150%)でも、はみ出さない。

### Steamで配るときの注意
- 遊ぶ人は、Steamのアカウントとクライアントが必要。シニア本人には、設定が難しいことがある。
  - 想定: 子の世代がインストールとログインを済ませて渡す。購入は、Steamのギフト機能で贈れる。
  - 一度ログインすれば、Steamの「オフラインモード」で、ネットなしでも遊べる。
- Steamを使わない配布(BOOTH・DLsiteなどの、`.exe` のインストーラー)も、あとから足せる。

## 10. UIデザイン案D(2026-11 決定。ゲーム画面に組み込み済み)
- 見本: `tools/ui_mock/mock.html?v=d`(画像: `ui_mock_d.png`)。A・B・Cは比較用に残してある。
- 配置: 右の列は画面の高さいっぱい(設計幅144=1920×1080で320px)。手牌は盤面の幅に収まる(1枚 約105px=画面の幅の5.5%)。
- 右の列: F1 メニュー(青) / F2 先生 あり・なし(緑) / F3 見送り 自動ON・OFF(オレンジ) / F4 解説(紫) / F5 せってい(灰色)。Fキーの札は同じ位置・同じ大きさ、文字は白の太字。
- Fキー: 対局中、F1〜F5 でも押せる(ブラウザの標準の働きは止める)。画面のボタンも、いつでも押せる。
- F3「見送り」: ポン・チー・カンの確認を出さずに見送る。ロンのときは、いつも確認を出す。リーチ中は対象外。設定は保存される。
- 見本の F4「並べ替え」は、手牌がいつも自動で並ぶので、実装していない(かわりに、既存の「解説」を F4 にした)。
- スタイルは `dlayout.css`(simple.css のあとに読み込む)。対局画面の他の部分(席の札・中央の枠など)は、まだ旧デザイン。
- シミュレーター(ブラウザ): `steam-mahjong/` で `python3 -m http.server 8000` → `http://localhost:8000/?quick=1`(タイトルを飛ばして対局開始。`&seed=源造,ナオミ,ショウ` で相手を指定)。
- まだ無い画像: タイトル・ロゴ・ボタン画像(`img/title_art.webp` など)、「あなた」の顔(`img/you/`)、先生の絵(`img/teacher/`)、ドラ表示の裏(`img/wall.webp`)。声(`audio/voice/`)は音声合成で代用。
