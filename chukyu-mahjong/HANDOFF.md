## 実装済み: 毎日スタンプ(`js/daily.js`)
- 起動してメニューに入ると、今日まだなら「📅 毎日スタンプ」が出る(起動ごとに1回)。カレンダーに「済」の印、連続日数、中級の目安を表示。
- 「最初に何を切る?」を1問(練習問題の牌効率と同じ問題。成績にも加算)。答えるとスタンプ。答え合わせから「🎴 対局へ」でつなぐ。
- 「スキップ」と「明日以降、起動時に表示しない」チェック。メニュー左上の「📅 スタンプ」からいつでも開き直せる(チェックも外せる)。
- 中級の目安: 牌効率・役・守備・鳴き・点数・押し引きの6分野で、10問以上かつ正解率70%以上で「わかった」。
- 保存先: localStorage `mj_daily`。

## 実装済み: ミスノート(`js/dojo.js` の `MJ.Mistakes`)
- 対局中、鳴きなし・リーチ者なしで、シャンテン数が戻る牌を切ると、その局面を保存(最大20件、localStorage `mj_mistakes`)。
- 毎日スタンプの1問が、保存した局面を優先して出す(「前の対局の場面: 何を切る?」)。正解で消え、間違いは3回まで残る。
- 局面から問題を作るのは `drill.js` の `genEffFrom`。

## 実装済み: 中級養成所(課題麻雀)(`js/dojo.js` の `MJ.Dojo`)
- ホームの「中級のコツ」カードを「🏯 課題麻雀」に差し替え(カードは10枚のまま)。モード id は `inter`。
- 課題14種(★1〜3): タンヤオ/ピンフ/役牌/リーチ/ツモ/ドラ3/七対子/一盃口/対々和/三色/一気通貫/混一色/満貫/ノー放銃。
- 課題を選ぶ(2回タップで決定)→ 相手選択 → 対局。課題の役で上がるとその場で終了してクリア。ノー放銃は最後まで振り込まなければクリア。
- クリアは localStorage `mj_dojo`。課題名は対局中の左上(局の下)に表示。
- 課題が「その局の途中経過」でどこまで近いかを出す機能(狙い役のアドバイス)は未実装。
