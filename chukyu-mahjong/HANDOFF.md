## 実装済み: 毎日スタンプ(`js/daily.js`)
- 起動してメニューに入ると、今日まだなら「📅 毎日スタンプ」が出る(起動ごとに1回)。カレンダーに「済」の印、連続日数、中級の目安を表示。
- 「最初に何を切る?」を1問(練習問題の牌効率と同じ問題。成績にも加算)。答えるとスタンプ。答え合わせから「🎴 対局へ」でつなぐ。
- 「スキップ」と「明日以降、起動時に表示しない」チェック。メニュー左上の「📅 スタンプ」からいつでも開き直せる(チェックも外せる)。
- 中級の目安: 牌効率・役・守備・鳴き・点数・押し引きの6分野で、10問以上かつ正解率70%以上で「わかった」。
- 保存先: localStorage `mj_daily`。

## 実装済み: ミスノート(`js/dojo.js` の `MJ.Mistakes`)
- 対局中、鳴きなし・リーチ者なしで、シャンテン数が戻る牌を切ると、その局面を保存(最大20件、localStorage `mj_mistakes`)。
- 毎日スタンプの1問が、保存した局面を優先して出す(「前の対局の場面: 何を切る?」)。正解で消え、間違いは3回まで残る。
- 局面から問題を作るのは `drill.js` の `genEffFrom`。

## 実装済み: 中級養成所(課題麻雀)(`js/dojo.js` の `MJ.Dojo`)
- ホームの「中級のコツ」カードを「🏯 課題麻雀」に差し替え(カードは10枚のまま)。モード id は `inter`。
- 課題14種(★1〜3): タンヤオ/ピンフ/役牌/リーチ/ツモ/ドラ3/七対子/一盃口/対々和/三色/一気通貫/混一色/満貫/ノー放銃。
- 課題を選ぶ(2回タップで決定)→ 相手選択 → 対局。課題の役で上がるとその場で終了してクリア。ノー放銃は最後まで振り込まなければクリア。
- クリアは localStorage `mj_dojo`。課題名は対局中の左上(局の下)に表示。
- 課題が「その局の途中経過」でどこまで近いかを出す機能(狙い役のアドバイス)は未実装。

- 下の1行に、スタンプ日数・連続日数・課題クリア数・中級の目安・対局数を表示(メニューに入るたびに更新)。

## 課題に合わせた打牌アドバイス(`js/dojo.js` の `Dojo.advice`、`coach.js` の `selfAdvice` から呼ぶ)
- 課題麻雀の対局中、解説の先頭に「🎯 課題」カード(今の手と課題の近さ)を追加。
- 手牌に印: 「課題✕」=課題から遠い牌(切りたい)、「課題◎」=課題に近い牌(残したい)。
- ★は、シャンテン数が悪くならない範囲で「課題✕」の牌を優先。通常の最善と違うときはカードで理由を説明。
- リーチ者がいるときは、★は通常どおり(守備優先)。鳴いた直後の打牌・ツモ和了のときは課題助言なし。
- 14課題すべてで例外なく動くことは確認済み。鳴くかどうか(`reactAdvice`)への課題助言は未実装。

## 課題麻雀: 鳴きの警告と達成までの数字(`js/dojo.js`)
- `Dojo.callCheck(game, p, o, kind, use)`: ポン・チーを課題から見て判定(ng=遠のく / warn=注意 / ok=近づく)。
  - 鳴きの選択カード(`ui.js` の `callCard`)に、ボタンの枠(赤=⚠・緑=◎)と理由の一文を表示。
  - 🎓解説の「🎯 課題からみた鳴き」カード(`coach.js` の `reactAdvice`)にも同じ内容。
- `Dojo.progress(game)`: 達成までの数字。左上の課題名の下に常時表示(例: 「么九牌あと4枚」「対子 3/7組」「あと2歩」「放銃0回 ◎」)。解説カードにも詳しい版。
- 動作確認: 14課題すべてで数字と鳴き判定が例外なく出ること、タンヤオ課題で1萬のポンに警告が出ることを画面で確認。
- 未実装: カン(大明槓)の課題判定、CPUが鳴いた場面の課題への影響表示。

## 課題を18種類に(追加4: ロン / 8巡目までにテンパイ / ダマテン / トップ)
- 巡目が条件の課題は `turnTest`(自分が切るたびに `Dojo.onDiscard` が判定、達成は局の終わりで確定)。順位が条件の課題は `endTest`(対局終了時に判定。早期終了なし)。
