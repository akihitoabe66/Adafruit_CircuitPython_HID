# 七つ目の記憶 ─ 夕霧中学校 旧校舎　仕様書（引き継ぎ用）

モノクロ2色・ディザ表現の一人称3D探索ホラーアドベンチャー。ブラウザだけで動く単一HTMLのゲーム。
見た目は *Return of the Obra Dinn* 風の1ビット表現、内容は *トワイライトシンドローム* 風の「学校の七不思議」を調べるアドベンチャー。

- 公開ページ（Artifact）: https://claude.ai/artifact/Be3CVvfkJryAvAGdWnHn2o
- リポジトリ: `akihitoabe66/Adafruit_CircuitPython_HID`　ブランチ `claude/school-mystery-adventure-game-9al645`
- ゲーム一式: `games/nanatsume/`

## 1. ファイルとビルド

| ファイル | 役割 |
|---|---|
| `game.html` | **ソース本体**。`<title>`〜`<style>`〜本文〜`<script>` を直接書いた断片（doctype なし）。Artifact にはこのファイルをそのまま公開する |
| `build.sh` | `game.html` から単体で開ける `index.html` を生成（doctype / head / body を付けるだけ） |
| `index.html` | 生成物。ブラウザで直接開いて遊べる。**直接編集しない** |
| `README.md` | 英語の概要と操作 |
| `SPEC.md` | この仕様書 |

- 外部依存: Google Fonts の **DotGothic16** のみ。ほかのライブラリはなし。
- 画像データ（顔イラスト7枚、シルエット）は base64 PNG として `game.html` に埋め込み済み（`FACE_SRC`, `SIL_SRC`）。
- 編集の流れ: `game.html` を編集 → `sh games/nanatsume/build.sh` → 動作確認 → コミット → Artifact を同じ `file_path` で再公開（URLは変わらない）。

## 2. 画面・操作

- 内部解像度 **384×216**、8×8 Bayer の順序ディザで2色に変換して表示（`image-rendering: pixelated`）。
- 2色パレットは手帳の「表示」で切替: Macintosh / IBM 8503 / Commodore 1084 / IBM 5151 / Zenith ZVM 1240 / 古写真。CSS 変数 `--ink` `--paper` も連動。
- 操作（PC）: W/S・↑/↓ 前後（**Shift で走る**、速度1.8倍）、A/D 横歩き、←/→ 旋回、**R/F 上/下を見る**、画面ドラッグで見回し、E・Space 調べる/話す、N 手帳、1〜9 で選択肢。
- 操作（スマホ）: 画面下のボタン（旋回・前後・横歩き・上/正面/下を見る）、「調べる・話す」「手帳」「走る（トグル）」。
- 会話: 画面下の枠に表示。左に話者の顔（ディザ化したイラスト）。幽霊は白っぽく走査線の入った顔。選択肢はボタン。
- セーブ: `localStorage` キー `nanatsume-v4`（`S` オブジェクトと位置）。形式を変えたらキーの番号を上げる。

## 3. エンジン（レンダラ）

`render()`（`/* renderer */` 節）。

- 列ごとのレイキャスト（DDA）。**セルごとに床の高さ `FH` と天井の高さ `CHT`** を持つ高さマップ方式で、段差（階段の蹴上げ）、天井の段差（まぐさ）、屋外の空を描ける。
- 壁は `WTOP`/`WBOT`（隣接セルから算出）までの高さで描画。`computeHeights()` で再計算（扉の開閉時など）。
- 視点: 目の高さ `EYE=1.5`、壁高 `WALLH=3`、FOV 66°、上下の見回しは画面のずらし（`PIT`、初期値14でやや下向き）。
- 深度は画素単位（`DEPTH`）、面の種類と ID（`SURF`）から**輪郭線**を描く（面の境目を黒線に）。
- 照明（`lightPix`）: 懐中電灯（画面中央の円錐＋距離減衰、明滅係数 `FLK`）＋固定ランプ `LAMPS`（宿直室の電気スタンドと扉からの漏れ光）。屋外は環境光少し。
- 天井の高い区画: 西階段の部屋と階段シャフトは天井 7.8。
- スプライト: ビルボード。`person` フラグの人物は**真っ黒なシルエット**、幽霊はさらに輪郭が白くちらつき、画素が欠ける。`emit` は自己発光（ランプ等）。一時スプライト `SCARE[]` も同時に描画。
- 窓の幽霊: `WING` が立っている窓セルだけ `TX.windowGhost`（白い人影入りの窓）に差し替え。
- 旧い「記憶（過去に入る）」モード用のコード（`MODE==='memory'`、`MEM`）は残っているが未使用。

```
x→ 0         10        20        30        40        50
y0  写真部(1-5) 音楽室(7-16) 理科室(18-30)  職員室(32-38) 一年一組(40-47)
y10 ───────────── 扉と表札 ─────────────────────────
y11-12 廊下（x1-48）　　　　　　　　　　　　　　　　 [壁Z]→二年三組(50-54, y8-15)
y13 ───────────── 扉と表札 ─────────────────────────
y14-21 西階段(1-5) 女子便所(7-13) 宿直室(15-19) プール(21-30) 保健室(32-35) 放送室(37-40) 図書室(42-47)
y22-25 階段シャフト（x1-2 が段）
y25-30 屋上（x1-12）、南と東は奈落（void）
```

- セル記号: `#` 壁 / `W` 窓 / `B` 黒板 / `K` 薬品棚 / `L` 本棚・棚 / `P` 個室の仕切り / `F` フェンス / `D` 木の扉（施錠） / `E` 屋上の鉄扉 / `U` 3番目の個室の扉 / `Z` 二年三組の隠し壁 / 表札 `H M R X J Y Q O C N A I` / 床 `.` `t`(タイル) `c`(コンクリ) `r`(屋上) `s`(階段) `p`(水) `v`(奈落)。
- 階段: x1-2、y14〜25 の12段（1段0.36）。屋上は13段目の高さ（4.68）。段の横から落ちない（見えない手すり）、挟まっても抜けられる（`canStand`）。
- 扉は `DOORS` で定義し、`applyDoors()` がフラグに応じて開閉。

## 6. ストーリー

1999年秋、取り壊し直前の旧校舎に新聞部の「私」が夜に忍び込み、七不思議を取材する。
真相は1979年11月2日（文化祭前夜）の事件:
答案の不正を知った澄子が黒田に殴られて死亡 → 柏木と黒田が遺体を理科室の収納棚へ → 透が撮影 → 黒田が西階段で透を突き落とす → ハルミが目撃して女子便所に隠れ、橘が保護 → カオルがカメラを拾ってプールへ、もみ合って黒田が溺死 → 夜明けに柏木が屋上から身投げ。

七不思議と真相:

1. 音楽室の夜のピアノ（澄子）
2. 理科室の歩く人体模型（棚に楽譜）
3. 西階段の十三段目（透）
4. 女子便所 三番目の個室（ハルミ）
5. プールの手招き（黒田）
6. 屋上の白い影（柏木）
7. 開かずの教室・二年三組（全員が集まる最終の場）

## 7. 謎解きの流れ（アイテム `S.items` / フラグ `S.flags`）

## 8. 驚かせる演出（`scares()`）

開始8秒後から、演出同士の間隔15〜30秒。毎回、心臓の鼓動（`heartRush`）が鳴る。

- 窓の外に白い人影が一瞬（窓7か所、`WINDOWS`、一度きり）
- 一年一組の奥に入ると、振り返った入口に人が立っている（見ると消える）
- 保健室のベッドに近づくと、カーテンの向こうで誰かが起き上がる
- 放送室に入るとスピーカーから雑音と「……たすけて……」
- 廊下の先を人影が横切る（最大3回）
- 懐中電灯の明滅（55〜105秒おき）
- 顔の一瞬表示 `faceFlash`（収納棚、プールの罠、二年三組、バッドエンド）
- 人体模型が近づく、女子便所のノックと返事、など

## 9. 音（Web Audio、すべてコードで合成）

- BGM（常時）: 低くうねるドローン＋音程の狂ったオルゴールがこだま（`bgmStart`, `musicBox`）。手帳でオン/オフ。
- 環境音: 7〜20秒おきにきしみ・水滴・遠くの足音・ささやき・鈍い音。幽霊が近いと心臓の鼓動（近いほど速い）。
- 「月光」: ベートーヴェン「月光」第1楽章冒頭を1音ずつ打ち込み（`MOON`、約50秒、パブリックドメイン）。音楽室にいるあいだループ、出ると止まる。楽譜を渡すと最後まで1回。
- 効果音 `sfx(name)`: shutter, crash, drag, knock, steps, fall, splash, bubbles, wind, chime, sting, step, creak, drip, farsteps, whisper, thump, heart, bang, static, buzz, moonlight/moonfull。

## 10. 動作確認のしかた

- Playwright（`/opt/node-tools/node_modules/playwright`、Chromium 同梱）で `index.html` を開いて確認していた。
- テスト時は `index.html` の末尾 `boot();` を置換して、内部へアクセスするフックを生やしたコピーを作る。例:
  ```
  sed 's#^boot();#window.T={S,set:(x,y,a)=>{px=x;py=y;pa=a;eyeH=fhAt(Math.floor(x),Math.floor(y));},tgt:()=>target\&\&target.label,act:()=>action()};boot();#' index.html > test.html
  ```
  `T.set` で位置に飛び、`T.tgt()` で調べられる対象名を確認し、`T.act()` で実行。会話は `#dialog` のクリック、選択肢は `#dlgOpts button`、メッセージは `#msgOk`。
- これで最初からグッドエンドまで全フラグが立つことを確認済み（最新版）。
- 構文チェック: `<script>` の中身を抜き出して `node --check`。
- 音は自動テストで聞けないため、鳴り方・音量は未確認。

## 11. ユーザーの好み・これまでの指示（守ること）

- 見た目はモノクロ2色ドット。3Dの人物は**黒いシルエットのみ**（顔や服の描き込みなし。名探偵コナンの犯人のイメージ）。
- 過去と現在を行き来する Obra Dinn の仕組みは**やめた**。普通のアドベンチャー（探索・会話・アイテム・謎解き）。
- 怖がらせる演出を多く、BGMは常時、心臓の鼓動を多用。
- 階段は立体で歩いて上る（ワープしない）。上下の見回しができること。
- 台詞と3D表示の矛盾を作らない（例: 「閉まっている扉」は3Dでも閉まっている、「明かりがついている」は実際に光が見える）。
- 返答・説明は日本語。
