# 企画: 年配向け 超操作シンプル麻雀(元: 麻雀・ギャンブラーズ v32 / 03a6480)

## 方針
- 操作は **十字キー + A(決定) + B(戻る)** だけで完結。マウス・タッチも引き続き可。
- 電源ON → 対局開始までを最短に(目標: Aボタン 1〜2回)。
- 対戦相手は自動。選択画面は出さない。
- 文字は大きく(本文の最小 目安 24px 相当・設計座標。老眼向け)。
- タイトル画像・キャラは後で差し替え(`img/` と `js/chars.js` を差し替えるだけにする)。

## 作業項目
1. 起動フロー: タイトル → (A) → 「はじめる / まなぶ」の2択 → 対局。相手は自動決定。
2. ホームを大ボタン3〜4個に削減(サポート対局 / 何切るクイズ / 設定)。ノート・辞典・クレジットは設定の奥へ。
3. サポートモード: 既存 `beginner` コーチを既定ON。解説は短文・大文字。
4. 何切るクイズ: 既存 `drill` の「何切る」だけを残し、2〜3択の簡単表示に。
5. 対局画面の簡素化: ボタンを必要時のみ表示(ツモ/リーチ/ポン/チー/パス)。牌と文字を拡大。
6. パッド操作: 牌選択は左右キー、A=捨てる、B=パス/戻る。上下キーは基本不要に。
7. 文字サイズ: 全画面で最小サイズを引き上げ、スクロールなしで収まるよう再レイアウト。
8. 残り(旧ノート等のスクロール画面)は新ホームから外す。

## 決まったこと(操作・表示)
- 起動の流れ: B案(タイトル → ホーム → 対局)。ホームは3ボタン(麻雀を打つ / 何を捨てる?クイズ / せってい)。「先生(サポート)」は「麻雀を打つ」の横で入り切り。
- 鳴きの確認: D案。文字だけのボタンを手牌の上に並べる。最初は「見送る」(右端)を選択、◀▶で切替、Aで決定、Bは無反応。出てから2秒はパッド/リモコンを受け付けない(マウス・タッチは対象外)。
  チーが複数ある場合は「チー」を選んで ▼ で牌の選択に入り、◀▶で組み合わせを切り替え、Aで決定、▲で戻る。
- 「戻る」(Fire TVのBack / B / Esc): 対局中は「対局をやめますか?」、タイトル/ホームは「アプリをおわりますか?」の確認(最初の選択は「つづける」)。いきなり終了しない。
- 画面の余白(セーフエリア)は取らない。テレビ側の調整に任せる。
- 文字サイズ: 32インチ〜75インチのHDテレビを想定し、実際の見た目で約20px以上(720pで画面高さの約2.8%以上)にそろえる。
- 対応画面: 推奨はHD(1280×720)以上。最小は1024×768(上下に黒帯が出るが崩れない)。1366×768、1920×1080でも確認済み。
