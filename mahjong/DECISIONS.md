# 決定事項: コンセプトと、段位・ポイントのきまり

(2026-10 の相談で決めたこと。実装の前に、画面の提案をお見せして、OKをもらってから進める。)

## ゲームのコンセプト(必須事項)
1. すぐ、簡単に始められる。
2. 勝った・負けたの結果から、自分の成長が目で見て分かる。
3. 点数計算を、このゲームで学んで、数えられるようになる。例題を解いて、点数が合っているか確かめる形式を、くり返しできる。
4. CPUを意識させず、歴史上の人物で、相手が分かりやすい。性格も、言葉づかいも、麻雀の打ち方も、人物のイメージどおり。
5. CPUは、対局中もしゃべり、人間と遊んでいるように動く。
6. 段位があり、難しすぎない、やりがいがある。
7. 毎日「麻雀をはじめる」を押すだけで、手軽に遊べる。
8. 突然やめても、自分の牌も相手も、打っていた続きから始められる。
9. 対戦相手に飽きたら、メニューに戻って、新しく相手を変えられる。東一局なら、止めてもペナルティなし。東二局以降は、完全に止める(新規で始める)と4位になる。そのときは、「4位で終了になりますが、よろしいですか?」と確認する。
10. 派手な演出で、爽快感がある。
11. 段位が上がるたびに、新しい相手(歴史上の人物)が増える。初段で★1の1人、二段で★2の1人、と、名人まで1人ずつ強い人が加わる。新しい偉人は、11人を用意する(絵と性格はこれから準備)。

### 保留していること
- **相手の出し方(コンセプト11):** 最初に使える相手の絞り方(例: 現在の★1〜★3の9人だけ)、現在の★4・★5を後出しにするか、強さ(★)の表示を10まで広げるか、★5のまま個性で強さを出すか。決まるまで実装しない。

## 段位とポイント
- 対象: 東風戦と東南戦(半荘)だけ。一荘は作らない。
- 順位ポイント(東南 / 東風): 1位 +30 / +15、2位 +15 / +7、3位 +5 / +2、4位 −10 / −5。
- **無段から始める**。認定証は、無段のあいだは出さない(ボタンも消す)。初めて初段になったとき、認定証にハンコが「バンッ!」と押される演出(画面の揺れ・音つき)。二段以降も、初めてなった段のときだけ同じ演出。降段のあとで再び上がったときは出さない。
- 段位の表(必要ポイント): 初段100 / 二段250 / 三段450 / 四段700 / 五段1000 / 六段1350 / 七段1750 / 八段2150 / 九段2550 / 十段2950 / 名人3400。
- 降段: その段に上がった時点の点(段の入口)から40点(4位4回ぶん)下回ったら、1つ下の段に降りる。**初段になったあとは、無段には戻らない。初段・二段は降段しない。三段以上は降段あり**。無段のときは、0点より下に減らない。
- 麻雀クイズ: 10問正解で +2点。1日の上限は +6点。
- 点数計算の勉強: カテゴリを読んで、チャレンジに正解したら +3点(各カテゴリの初回だけ)。
- ポイントが入ったときは、理由を短く表示する(例: 「+2点 クイズ10問正解」)。
- 目安: 週2〜3回の半荘で、名人まで約1年4か月(全勝なら約9.5か月、毎日遊んで全勝なら約4か月)。数値は、遊びながら調整する。

## 麻雀先生の評価と特訓(実装ずみ)
- クイズ: 直近30問の種類別の正解率。苦手(80%未満、低い順に2つ)から、10問の特訓(6問+4問)。
- 対局: 直近20局の和了率・放銃率・副露率・平均和了点・リーチへの放銃。入口は、戦績の画面とクイズの答え合わせの画面。

## 実装の順(おすすめ。どれも、実装の前に画面の提案をして、OKをもらってから進める)
1. 段位・ポイント一式(無段、ハンコの演出、ポイント表示、降段、クイズと勉強のポイント)
2. 局の途中の保存と、放棄は4位(#8と#9)
3. 「前回と同じ相手で、すぐ始める」ボタン(#1と#7)
4. 点数あてドリル(#3)
5. 相手が増える仕組みと、新しい11人(#11。相手の出し方を決めてから)

## 季節牌(花牌) ルール(実装ずみ。ルール設定で、初期値は「なし」)
- 春・夏・秋・冬の4枚(牌番号 34〜37)を、山に加える(140枚)。ドラ表示牌・嶺上牌(王牌)には入らない。
- 引いたら(配牌のときも)すぐ脇に出して、山の最後尾から1枚補う。補った牌が季節牌なら、くり返す。切れない。手牌は13枚のまま。
- 1枚ごとに +1飜(「花牌(季節牌)」として表示)。ドラと同じで、役がある和了のときだけ数える。役満には加えない。
- 季節牌は、各自の名札のそばに小さく並べる。引いたときは、「花」と知らせる。

## CPUの速さ(実装ずみ。初期値は「ふつう」)
- 設定の「CPUの速さ」と、対局中の「音のせってい」から、思考 → ふつう → 高速 と切り替える。次のCPUの手番から効く。
- 高速: 1打 約0.3秒。ふつう: いまの間(約0.7〜2.1秒)。思考: 約1.5〜3秒+ためらい。
- 思考のためらい(吹き出し): テンパイでリーチを迷うとき(長め、麻雀先生ありなら「長考しています。テンパイかもしれません」)、リーチ者がいるときに現物でない牌を切るとき(約45%)。CPUの強さは変わらない。

## CPUのセリフの出る間(実装ずみ)
- 牌を捨てたときのひとこと(つぶやき・いやみ・反応)は、捨てた牌が見えるように、約0.8秒あとに出す(高速は0.4秒後)。出ている時間は約2.4秒(高速は1.6秒)。待ち時間は増やさない(タイマーだけ)。そのあいだに次の牌が捨てられたら、出さない。
- 牌を捨てる瞬間に、出ている吹き出しは消す(思考モードの「ためらい」は、捨てる前に出て、捨てる瞬間に消える)。
- 高速では、ひとことの頻度を約半分にする。リーチ・ポン・ロンなどの宣言は、これまでどおり。

## セリフは同時に1人だけ(実装ずみ)
- CPUの吹き出し・カットイン・麻雀先生・宣言(リーチ・ポンなど)のうち、出ているものが終わるまで、次のCPUのセリフは待つ。約2.5秒待っても出せなければ、やめる(古いセリフを出さない)。
- 麻雀先生が優先: 先生が話すときは、出ているCPUのセリフは、すぐ消える。先生が出ているあいだのCPUのひとことは、出さない。
- 宣言の最中は、ほかのセリフを出さない。
- 思考モードの「長考しています。テンパイかもしれません」(麻雀先生)は、捨てたあとに言う(CPUの「うーん…」と重ならない)。

## セリフの読む時間(修正。上の「CPUのセリフの出る間」より、こちらが新しい)
- ひとことは、出したら、読み終わるまで消さない(短いセリフでも2.8秒。長いセリフは文字数に応じて、最大4.8秒)。次の人が牌を捨てても、消さない。消えるのは、麻雀先生が話すとき・宣言のとき・その人自身の「考え中のセリフ」(捨てる瞬間)だけ。
- 捨てたあと約0.8秒で出す(待ち時間は増やさない)。
- 高速は、読み切れないので、牌を捨てたときのひとことを出さない(宣言・リーチなどのセリフは、そのまま)。

## 捨て牌のひとことと、ポン・チーの交通整理(実装ずみ)
- 牌を捨てたあとのひとこと(0.8秒後)は、ロン・ポン・チー・カンの判断が終わるまで待つ(判断中は出さない)。
- 鳴かれた・ロンされたときは、捨て牌のひとことは出さない(ポン・チー・ロンのセリフが、きれいに出る)。
- 判断に3.5秒以上かかったとき(あなたが迷っているとき)や、先に進んだときは、古いセリフなので出さない。

## 局のはじまりの演出の順番(修正)
- 東二局以降: 前の局の牌を消す → 「東二局」の枠が落ちてくる(2.5秒表示) → サイコロ → 配牌。以前は、サイコロのあとで、すぐ次に進んでいた。
- 最初のコマから見えるように、親の顔の絵を先に読み込み、卓が空になった画面を描いてから、動かしはじめる。

## 演出の強さと、読み込みの軽量化(実装ずみ)
- 設定の「✨ 演出」: 豪華 / ふつう / 軽量。豪華=すべて出す。ふつう=桜は8枚、揺れ・ぼかしなし。軽量=桜・ぼかし・影・揺れ・閃光なし。
- Windowsの「アニメーションを表示する」がOFFでも、演出は消さない(以前は、この設定で、桜・「勝負!」の演出が、すべて消えていた)。
- 自動判定: 演出を選んでいないとき、起動直後に3秒測り、毎秒15コマ以下なら、自動で「軽量」にする。設定に「(自動)」と出る。自分で選んだら、そちらが優先。
- 画像は、WebPに変えて、サイズを統一した(牌 104×138、顔 240×240、あなた 240×240、麻雀先生 高さ240、キャラの絵 高さ327)。画像は15MB→約3MB。音は64kbpsにして、36MB→約21MB。起動時に読み込む量は約4MB。
- 次: 実機(DG-STK3)で測定して、その数字で、次の対策を決める。

## 初回のもたつき・コントローラーのカーソル(実装ずみ)
- 「はじめる」を押した直後に、読み上げ(音声合成)の準備をしていた。Windowsでは、これが数秒、画面を止めることがある。→ 最初のタップでは行わない。
- 音の出口(AudioContext)は、タイトルが落ち着いてから、先に作る。ホームの背景の変換と最初の描画も、タイトルのうちに済ませる。
- 「はじめる」: 先にホームを出し、音・BGMは、1コマ描かれたあとに行う。曲の取り寄せは、ホームが落ち着いて(5秒後)から、1曲ずつ間をあけて行う。クイズの先読みは3秒後。
- 対局の描き直しは、変わった所だけにした(手牌の光が、ぴょこっと動くのを防ぐ)。
- コントローラーのカーソル: 配牌のあと、手牌に置く(いちばん右)。自分の番になったら、引いた牌に。他家の番のあいだは、動かさない。捨てたあとは、同じ位置に残す。
- 設定の「動作の測定」に、止まった記録(50ミリ秒以上)と、「はじめる」の内訳を出す。

## コントローラーのボタン割り当て(実装ずみ)
- 古いUSBコントローラー(スーファミ型)は、「標準」でない並びで届く(0=X 1=A 2=B 3=Y)。標準でないコントローラーは、A(右)=決定、B(下)=もどる、にする。標準(Xbox型)は、0=決定、1=もどる、十字=12〜15。
- 合わないときは、設定の「🎮 コントローラー」で、決定・もどるに使うボタンを、押して、おぼえさせられる(コントローラーごとに保存)。「自動にもどす」で、元に戻る。
- 十字キーが、軸(0・1)や、ハット(軸9)で届くコントローラーにも対応。

## Bボタン(戻る)と確認(実装ずみ)
- 確認なしで戻る: 設定(→ホーム)・設定の中の画面(→設定)・麻雀先生の評価(→クイズ)・用語辞典などの板(閉じる)・学ぶページの2ページ目以降(前のページ)。結果のダイアログと、鳴き・ロンの確認では、Bは何もしない。
- 確認あり(「つづける」が最初に選ばれ、出て0.6秒は入力を受け付けない): タイトル(終了)・ホーム(タイトルへ)・相手選択(ホームへ)・対局中(やめる)・クイズ(ホームへ/勉強の一覧へ)・特訓(やめる)・勉強の一覧(ホームへ)・学ぶ1ページ目(一覧へ)・チャレンジ(一覧へ)。
- 設定でBが効かなかった原因は、「◀ もどる」の名前が、戻るボタンの探し方と合わなかったこと。
- コントローラーの入力は、画面の描画に加えて、10msごとにも読む。入力が遅れた記録(120ms以上)は、設定の「動作の測定」に出る。

## オフライン版(Windows・Edgeのアプリ表示)
- 「start.bat」で、Edgeが、アドレス欄のないアプリの形で、パソコンの中の game\index.html を開く。ファイルの読み込み許可・音の自動再生許可・専用の保存場所つき。
- ファイルとして開いたとき(file://)は、fetch の代わりに XMLHttpRequest を使い(`MJ.fetch`)、曲の先読み(Blob)をやめ、背景の絵は直接読む。
- 次: DG-STK3で、ブラウザ版と比べて、速さを測る(「動作の測定」)。効果があれば、WebView2版(軽い)かElectron版(標準)を作る。

## タイトル画面のコントローラー操作(確定)
- 初めはどのボタンも光らせない。Aで「はじめる」。方向キー(↑=BGM、↓/→=おわる)で、そのボタンが光る。光っている間は↑↓で行き来、←かBで光を消す(Aは「はじめる」に戻る)。
- 光る枠は四角ではなく、ボタン(画像)の輪郭に沿った白いふち+青い光(drop-shadow)。おわるは角丸に沿う。他の画面は、確認してから広げる。

## 操作の速さ・ゲーム中の操作(確定)
- キー/ボタンの受付は、待ち時間を入れない(Bの確認ダイアログ直後の0.6秒ロックを廃止。ポン/ロンの確認の直後だけ0.6秒)。長押しの繰り返しは 0.26秒→0.07秒間隔。
- 手牌の左右は、位置計算なしで隣の牌へ。左端でさらに左=右のボタン列へ、右のボタン列でさらに右=左端の牌へ(ぐるっと一周)。牌の説明表示は動きが止まってから(90ms)。
- 上家・下家のキャラ(セリフ・宣言)の高さを同じにした。
- 「勝負!」・サイコロは、画面が切り替わって落ち着いてから(約0.4秒)アニメを始める。
- 設定に「🖥 画質」(きれい/ふつう/かるい)。高さ720/540で描いて拡大する。実機(DG-STK3)で速くなるか確認してから既定を決める。
- 検討中: ゲーム中の「あなたの番です」表示(カーソルは消さず、解説・ボタンを押せる形で)。

## ゲーム中のカーソル(確定)
- 自分の番が来ても、カーソルを勝手に動かさない(カーソルが無い時だけ、引いた牌に置く)。手牌の上で「↓」=引いた牌(14牌目)へすぐ戻る。
- 自分の番は「あなたの番です」を短く表示し、引いた牌を金色に光らせる(青いカーソル枠とは別物)。

## 河(捨て牌)の並び(確定)
- 本物の麻雀と同じく、各席から見て左から並べる(最後の段が短くても、中央に寄せない)。

## 画面切り替えの軽量化(実測にもとづく)
- ゲーム画面に入る時間の大半は、解説パネル(閉じていても毎回作っていた)の文字合わせ。閉じている間は作らず、開いた時に1回だけ作る。文字合わせは二分探索に。
- 通常形の向聴数を、色ごとに組み合わせを覚える方式に置き換え(結果は同じ、重い手で約10倍速い)。
- サイコロ・「勝負!」画面が、1080pなどで1.5倍に拡大されて端が切れていた不具合を修正(画面の大きさを親の箱から求める)。
- サイコロ: 豪華以外は、立体の回転をやめて平らな目の入れ替わりに。ぼかし影・光の影(filter)を廃止。サイコロの間は、裏の画面の文字合わせをしない。
- BGM: 44.1kHz ステレオ64kbps → 22.05kHz モノラル48kbps(再生時の処理を軽く、サイズも約25%減)。
- サイコロの駒は一辺を約66%に(受け皿はそのまま)。描く面積が約43%になり、受け皿の中に余裕をもって収まる。
- 音と絵の同期: 局の始まりの「ドン」(東一局)・勝負!・サイコロの転がる音は、画面の動きが実際に始まった時(animationstart)から数える。始まる前に画面の準備(2コマ+約0.2〜0.4秒)を待ち、動きは止めておく。
- 「あなたの番です」は、手牌の中央の上に、大きく(30px)出す。
- カーソルの牌の持ち上がりはアニメなし(引き直しで上下に動かない)。解説パネルは、対局の配置が決まる前は隠し、閉じる時の動きもなし(開く時だけ動かす)。
- サイコロの駒は一辺を約55%に。

## 描画の軽量化(第2弾・確定)
- 動かすのは位置・拡大・透明度だけ。ぼかし(filter/backdrop-filter)・動く影・光る影はやめる。叩きつけの拡大は約2倍(以前は3.4〜4倍)。
- 引いた牌は光らせない。山から右はしへ「タンッ」と置かれる動き(0.2秒)で知らせ、14牌目は少し離れた位置のまま。
- 手番の名札は、光らず、少し拡大+黄色い枠。
- ポン・チーの確認は、出る時の動き・半透明をやめる(最初からはっきり)。
- 演出の前に「じゅんび中…」を出す(緑の無地で止まって見えないように)。牌・顔の画像は、タイトルが落ち着いた後に先読みして画面に出せる形にしておく。

## 画質・ホームの軽量化
- 画質の設定を5段階に: きれい/ふつう(高さ720)/かるい(540)/もっとかるい(432)/いちばんかるい(360)。
- 左上のロゴ画像を 560px → 380px 幅に。ホームの4つのボタンを小さく(高さ74→58、文字42→34、幅も狭く)。
- 検討中: 起動のスプラッシュ化(タイトルをすぐ出して、裏で読み込み→自動でホームへ)と、読み込む画像の段階分け。
- 起動: タイトルに必要な絵(背景・ロゴ・ボタン)だけでタイトルを出し、牌・顔・ホームの背景などは、タイトルのあと裏で読み込む(CPU6倍遅で、タイトル表示 3.2秒→1.1秒)。「はじめる」を押した時、まだ終わっていなければ最大2.5秒待つ。
- 画像の解像度: 顔・あなたの絵 240→176px、立ち絵 高さ327→240、タイトルのボタン 527→360 / BGM 210→150。牌(104×138)は、読みやすさのため、そのまま(軽さへの効果が小さい)。
- 発言・宣言・カットインのキャラの表示を、少し小さく(112→96 / 118→100 / 130→110)。
- 検討中: 自動でホームに移るスプラッシュ(音の制約があるため、BGMの扱いと合わせて)。
- BGM: 押さなくても鳴らせる環境(Windows版start.bat=ファイルとして開く/自動再生が許可されたブラウザ)では、タイトルが出て1秒後にホームの曲を流す(「はじめる」で曲は途切れない)。許可がない環境(iPhone・通常のブラウザなど)は、今まで通り最初の操作から。start.bat は、起動時にmp3と牌の画像をOSのファイルキャッシュに先読み(裏で)。
- タイトルの方向キー: BGM(右上)・はじめる(下の中央)・おわる(右下)の3つを選べる。初めは何も光らせない(Aではじめる)。初めの1回は ↑=BGM / ↓→=おわる / ←=はじめる。光っている間は、方向で、ほかの2つへ移れる。
- ダイアログの大きさ: 画面全体の拡大率の約6〜8割(確認=6割、設定などの一覧=8割)。画質を低くしても、画面いっぱいにならない。

## ページ式ダイアログ(上がりの結果など)の操作(確定)
