# シニア向けの見た目のルール(操作シンプル 本格麻雀)

介護施設の掲示や、案内表示でよく使われる考え方(ユニバーサルデザイン)を、ゲーム画面に当てはめたものです。

## 基本
1. **1つの画面で、していいことを1つに絞る**。ボタンは、多くても4つ(ホーム)。
2. **文字は大きく**。本文は、実際の見た目で約28px以上(HD画面)。補助の文字でも約20px以上。
3. **高いコントラスト**。暗い背景に白、明るい面に黒。薄い灰色の文字は使わない。
4. **色だけで伝えない**。形・記号・位置・大きさも一緒に使う(✓ ⚠ ▶ など)。赤と緑だけの区別は避ける。
5. **同じ働きは、いつも同じ場所・同じ形**。「決定」はA、「戻る」はB(ただし鳴きの確認ではBは使わない)。
6. **やさしい言葉**。「リーチ」「ロン」など麻雀の言葉は残し、説明は短く、専門用語には言い換えをつける。
7. **間違えても取り返せる**。取り返せない操作は、確認を出して、最初の選択は「安全な方」にする。

## 選んでいるボタン
- 選んでいるボタン: **黄色の面 + 黒い太枠 + 白い縁 + 少し拡大 + ▶の目印**。
- 選んでいないボタン: うすい色の面 + 黒い文字。
- 画面が出た時点で、最初のボタンを選択状態にしておく(パッドを押す前でも、色で分かる)。

## 重要度による見せ方
| 重要度 | 例 | 見せ方 |
|---|---|---|
| 重大(取り返せない・止める) | 「おわる」「リセットする」「ホームにもどる」 | **赤の面 + 白文字 + ⚠**。最初の選択は、必ず安全な方(「つづける」「やめる」)。 |
| 注意(いま選ぶ必要がある) | 鳴きの選択、クイズの答え、メニュー | **黄色で選択中を示す**。ボタンは大きく、文字は太く。 |
| 結果(正解・不正解) | クイズの答え合わせ | **大きな色の帯 + 記号**(⭕緑 / ❌赤 / △橙)。文字は大きく。 |
| ふつうの情報 | 先生のひとこと、勉強の文章 | 白い文字、読みやすい行間。 |
| さりげない情報 | 操作の案内(下の帯) | 小さめ(約20px以上)。常に同じ場所。 |

## これから
- 勉強の文章に、やさしい言い換えと、図(牌の並び)をもっと足す。
- 対局中の画面の、細かい表示(河の牌・札)の整理。
- 「苦手」を一覧で見られる画面(正解率)。
