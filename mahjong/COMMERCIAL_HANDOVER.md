# 商用の別プロジェクト(Steam・スマホ)への引きつぎ

目的: このゲームの「しくみ(コード)」を土台に、画像・声・音楽・キャラを入れかえて、別チャンネルの新しい麻雀ゲームとして作る。
(これは技術の整理です。 権利・規約の判断は、必ず ご自身で 元の規約を読んで確認してください。 ここに書いた「要確認」は、私が 確かめられなかったものです)

## 1. 引きつぎかた(おすすめ)
1. `sh tools/export_clean.sh /書き出すフォルダ` で、**履歴なし・素材なし**の きれいな一式を作る(コード・文書・素材づくりの道具だけ)。
2. 別チャンネル側の **新しいリポジトリ**(空)に、そのまま push する。 このリポジトリを fork しない(履歴に ずんだもんの素材・他人の動画が 残るため)。
3. 新しいリポジトリでは、`audio/` `img/` `video/` を、自分たちの素材で作る(下の一覧)。

## 2. しくみの地図(使いまわせるもの)
| 場所 | 中身 | 商用で使いまわせるか |
|---|---|---|
| `js/` | ゲームの頭脳(牌・役・点数・AI・局の進行)と、Web版の画面 | ◎ 自作。 そのまま土台に |
| `index.html` `style.css` `simple.css` | Web版(`window.MJ`)。 ブラウザ・スマホで動く | ◎ |
| `android-app/` | Capacitor でのスマホ(Android)包み | ○ iOS も Capacitor で同じ形にできる |
| `native/app/` | SDL2 + QuickJS の 自前の実行系(Raspberry Pi 専用機向け) | △ Steam は これを使わず Web版を包む方が楽(下) |
| `native/pi/` | OLED・ブザー・コントローラー(Pi専用機の部品) | × Steam・スマホでは不要 |
| `tools/` | 素材づくりの道具(音声生成・画像の切り出し・地図の道すじ など) | ○ 素材を入れかえるときに使う |

### Steam・スマホの作りかた(案)
- **スマホ**: `index.html` を Capacitor(`android-app/` の形)で包む。 iOS も同じ。
- **Steam**: `index.html` を Electron か Tauri で包んで出す(Steamworks は Greenworks / steamworks.js など)。 ゲームパッドは `js/pad.js` に あります。
- 「Pi版 UI(`native/app/nui.js`)」は 専用機向けの別の画面です。 Steam・スマホ版は **Web版の画面(`js/ui.js`)を土台**にするのが近道。
- 新しい規格(ルール)に するときは、`js/rules.js`(役・点数)・`js/game.js`(進行)・`js/ai.js`(CPU)を 変える。 ルールの切りかえ口は `MJ.RULES`(設定画面の「麻雀のルール設定」)。

## 3. 入れかえる素材の一覧(ここが 商用で いちばん大事)
| 素材 | 場所 | いまの出どころ | 商用の注意(要確認) |
|---|---|---|---|
| ずんだもんの声 | `audio/yk/` `audio/voice/` | VOICEVOX:ずんだもん で生成(`tools/gen_voicevox.py`) | VOICEVOX・ずんだもんの利用規約・クレジット表記の条件を確認。 **新作では 別の声に入れかえる予定** |
| CPUの掛け声 | `audio/voice/` | Open JTalk(Mei, CC BY 3.0) | 商用可だが クレジット表記が必要 |
| 声の台本・割りあて | `audio/yk/manifest.json` `js/chars.js` `js/banter*.js` | 自作 | ◎ 台本は そのまま使える。 声だけ録りなおし(`tools/gen_voicevox.py` が 使える) |
| ずんだもんの絵(顔・ポーズ・OLED) | `img/zunda/` `img/t*/` `img/teacher/` ほか | 東北ずん子・ずんだもんの キャラ | **キャラ自体の利用ガイドラインを確認**。 新作では 自分たちのキャラに入れかえ |
| 対戦相手の絵・地図・認定証 など | `img/` | 画像生成AIで 制作 | 使った生成サービスの **商用利用の条件**を確認 |
| BGM | `audio/*.mp3` | 生成した曲 | 使った生成サービスの **商用利用の条件・プラン**を確認(曲ごとに) |
| 効果音 | `audio/sfx/` | `tools/gen_sfx_wav.py` などで 自作(合成) | ◎ 自作なら そのまま |
| ビデオ(動画) | `video/` | **他の人の YouTube 動画** | × **入れてはいけません**。 商用の書き出しには 含めていません |
| フォント | 実行時に システムのものを 使用(IPAゴシック など) | IPAフォント | 同梱するなら IPAフォントライセンスの文を つける |
| 牌の絵 | `img/tiles/` | 要確認(自作か生成か) | 要確認 |
| クレジット画面 | `tools/make_credits_img.sh` / `nui.js` の CREDITS | 自作 | 新しい素材の出どころに 書きかえる |

## 4. 名前・ブランド
- 題名「シンプル操作 AI本格麻雀」・ロゴ・ずんだもん・キャラ名(歴史上の人物は 名前そのものは 自由。 絵は 別)・声の台詞の 言いまわしは、新作では 見直す。
- Pi専用機の名前や 義母さん向けの設定(`DESIGN_SENIOR.md`)は、新作の対象に あわせて 取捨選択。

## 5. 新しい人が 最初にやること
1. `README.md` → `DECISIONS.md`(なぜ こう作ったか) → `HANDOFF.md`(Web版の構成) の順に読む。
2. `index.html` を ブラウザで開いて、Web版が動くのを 見る(素材を 入れる前は 画像・音が出ません。 `img/`・`audio/` の README を見る)。
3. キャラ(`js/chars.js` `js/roster.js`)と 声(`audio/yk/manifest.json` の キー)の対応を 見て、自分たちの声・絵に 入れかえる。
4. 入れかえが 済んだら、`tools/` の道具で 地図・認定証などを 作りなおす。

## 6. このリポジトリでは 引きつげないもの
- 他の人の動画(`video/`)。
- ずんだもん・VOICEVOX・生成AIの 素材の「権利」そのもの(コードと違い、引きつげるのは 規約を 守って 使う権利だけです)。
- 履歴(git log)。 新しいリポジトリは 空から はじめます。
