# 麻雀・ギャンブラーズ

麻雀の基本ルールは分かるが、役の作り方・捨て牌の考え方・点数計算に自信がない人向けの
**4人対戦麻雀ゲーム**(ブラウザで動く、外部ライブラリ不要)。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(サーバー不要)。

```
cd mahjong
python3 -m http.server 8000   # 任意。 http://localhost:8000/ を開く
```

## モード

| モード | 内容 |
| --- | --- |
| フリー対戦 | 好きな CPU 3人と自由に対戦。「ヒント」ボタンでいつでもアドバイスの ON/OFF |
| 入門: 役づくり講座 | 手牌を一緒に見ながら、シャンテン数・おすすめ打牌・狙える役・鳴き(ポン/チー/カン)の可否・フリテン等を解説 |
| 捨て牌特訓: 守備 | 手牌の各牌に **現物 / スジ / カベ / 字牌 / ワンチャンス** の安全度ラベルを表示。リーチ者への安全牌ランキングと放銃の振り返り |
| 中級のコツ | 押し引き判断・打点(ダマとリーチの点数比較)・待ちの良し悪し・順位状況などを解説 |
| 📝 練習問題 | 何切る(牌効率)・狙える役・守備(現物/スジ/中スジ/カベ/字牌のテーマ別も選べる)・鳴き判断・待ち当て・点数計算(飜/符/点数)・**押すか引くか**・**リーチかダマか**を、**毎回ランダムに作られる問題**で練習。答え合わせで理由を解説し、正解数を記録します |
| 📚 用語辞典 | 約110語の用語集。**チートイ/ニコニコ(=七対子)**など地域・世代で違う俗称でも検索可。解説文やノート内の専門用語は黄色の点線でハイライトされ、タップすると説明ダイアログが出ます(対局中は📚ボタンからも開けます) |
| 麻雀ノート | 役一覧、点数計算(符の数え方・点数早見表)、スジ/カベ、鳴き、用語集 |

どのモードでも、**和了するたびに「点数計算のしくみ」(役→飜→符→基本点→支払い)を解説**します。
放銃したときは「もっと安全な牌があったか」を振り返ります。

## 対戦相手

`img/chars/01.jpg〜16.jpg`(添付いただいた一覧画像から切り出した顔写真)の16キャラクターが登場。
各キャラには強さ(★1〜5)と打ち筋(攻め/守り/バランス)があります。

* ★1(入門): ミスが多い。押し引きなし
* ★2(初級): 牌効率はできるが守備はしない
* ★3(中級): 牌効率 + 現物による簡単な守備、役牌・タンヤオの鳴き
* ★4(上級): スジ・カベも考慮した押し引き、ダマ判断、混一色の鳴き
* ★5(達人): 失点期待値を重く見た押し引き

## 実装済みルール

4人打ち・25000点持ち・赤ドラ(各色1枚)・喰いタンあり・東風戦(東1〜4局)/1局戦、
リーチ・一発・裏ドラ・ツモ・ロン(ダブロンあり)・ポン・チー・カン(暗槓/大明槓/加槓)・食い替え禁止・
フリテン(自分の河/見逃し/リーチ後)・流局(テンパイ料)・連荘・本場・供託、
役(役満含む主要役)と符計算・点数計算。

※ 未実装: 九種九牌・四風連打・四家立直などの途中流局、流し満貫、搶槓、ダブル立直、天和/地和。

## ファイル構成

* `js/tiles.js` 牌の定義と SVG 描画 / `js/rules.js` 向聴数・面子分解・役・符・点数
* `js/ai.js` CPU の思考と牌効率・危険度の分析(コーチと共用) / `js/chars.js` キャラクター
* `js/coach.js` アドバイス生成 / `js/game.js` 対局の進行 / `js/ui.js` 描画・入力 / `js/lessons.js` ノート

## 音

* BGM: ホーム画面は `audio/home.mp3`(thirteen_black_tiles)のみ、対局中は `audio/game1〜3.mp3`(silk_and_steel / winning_hand_at_midnight / the_final_straightaway)からランダムに選曲して順に再生。iPhoneでも音量が効くよう WebAudio で調整します
* 効果音: WebAudio で合成(クリック・牌をつかむ/捨てる・ポン/チー/カン・リーチ・ロン/ツモ・和了/敗北ジングル等)
* 掛け声(ロン!・ポン!・チー!・カン!・リーチ!・ツモ!): `audio/voice/<キャラid>_<種類>.mp3` に収録済み(端末や環境に依存しません)。HTS Voice "Mei"(MMDAgent Project Team / 名古屋工業大学, CC BY 3.0)を Open JTalk で合成し、キャラごとに音の高さ・速さを変えています
* 「⚙ 設定」でBGM・効果音・掛け声のON/OFFと音量を変更できます
* 🔊 読み上げ: アドバイスと結果画面の文章は動的に変わるため、ブラウザ標準の音声合成(Web Speech API)で読み上げます。日本語音声が入っている環境で、女性の声を優先して選びます(端末の音声に依存)

## 画面レイアウト

対局画面は固定比率の「ステージ」で表示し、スクロールバーなしで画面内に収めます。PC・タブレット横は16:9を基準に拡大縮小、スマホ縦は9:16〜9:19.5、スマホ横は16:9〜19.5:9。比率が合わない分は暗い背景(黒帯)になります。解説は1枚ずつ ◀▶ で切り替え、縦画面では下の解説パネルをタップすると大きく開きます。

## キャラのセリフ(掛け合い)

CPUキャラが、局の開始・あなたの打牌(東・ドラ・赤・字牌など)・リーチや鳴きに反応して、吹き出しやカットインでしゃべります(各キャラ約30種)。**答えバレ防止**のため、出るタイミングと内容は相手の手牌とは無関係に、固定の確率でランダムに選びます。設定の「キャラのセリフ」でON/OFFできます。セリフは `js/banter.js` に追記すると増やせます。

## スマホ縦持ちの表示

縦持ちのスマホでも、対局画面は横画面レイアウトを90°回転して表示します(スマホを横に倒して遊びます)。設定の「スマホ縦持ちの表示」で「縦画面のまま」にもできます。画面比率が合わない端末では、暗い背景の帯が付きます。

## 結果画面

上がり(和了)のたびに、役の名前を音声で自動読み上げします(例: 「リーチ、イッパツ、ツモ、サンショク、ドラ2。…点」)。ロンされた(放銃した)ときは、「何が起きたか / なぜ当たったか / リーチ後の自分の切り牌の記録 / 次はこうしよう」の4段階で詳しく振り返ります。🔊ボタンは振り返りの部分を読み上げます。相手キャラが勝った場合は、そのキャラの自慢のセリフも出ます。

## 結果画面のBGMと振り返り

結果画面では、自分が上がったとき(Full Credit Sequence)、自分がマイナスだったとき(Leaving the Late Cafe)、流局のとき(Sunday Avenue)で専用BGMが流れます(閉じると対局BGMに戻ります)。放銃(ダマテン含む)と流局では、相手がテンパイしていた間のあなたの切り牌を記録して、危なかった牌・安全だった牌・手が崩れた場面を振り返ります。流局は山が残り16枚(あと4回引けるころ)の打牌を中心に振り返ります。
