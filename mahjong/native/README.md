
## セーブ・メニュー(Pi版)
- 局が終わるたび「セーブして次の局へ / セーブしないで次の局へ」(手動のみ。オートセーブなし)。
- セーブは `~/mjdata/save_<連番>.json`(環境変数 MJ_DATA で変更可)。最新5件を保持。別名で書いてから名前を変えるので、電源断でも前のものは壊れない。
- タイトルの「つづきから」=最新のセーブ。隠しコマンド(タイトルで 上 上 下 下 左 右)=5件から選んでロード(ロードすると一覧は消える)。
- スタート+セレクトを1.2秒長押し=メニュー(つづける / ホームにもどる / おわる)。Ctrl+Q でも終了。

## CPUの速さ(Pi版)
- タイトルの「CPUの速さ: ふつう/高速/思考」を決定ボタンで切り替え(メニュー(スタート+セレクト長押し)にもあり。保存される)。
- デバッグ用: `MJ_CPU=fast ./native/app/mj .`(起動時に指定)。
- Pi版ではCPUの思考の時間上限を0.4倍に縮めてある(`MJ.AI_BUDGET`)。考えている間は画面・入力が止まるため。

## 絵のバージョン(浮世絵版)
- ふだんは「浮世絵版」の絵(`img/uk/`: CPU32人・あなたの16表情・タイトル)を使います。
- 起動のとき環境変数 `MJ_STYLE=old` を付けると、前のバージョンの絵(`img/chars`・`img/zunda`・`img/title_art.webp`)に戻ります。 例: `MJ_STYLE=old ./mahjong`
- 浮世絵版の絵は `python3 tools/cut_ukiyoe.py` で、`tools/ukiyoe/` の元絵から切り出します(顔の大きさ・位置は、このファイルの `SCALE` `SIZE` `UP` `EYE` `YOU_SCALE` で調整)。

## ビデオ(ゲームの中で再生)
- 動画(.mp4)は、次のどれかの場所に入れます。 git で配る動画は、リポジトリの `mahjong/video/` に入っています(`git pull` だけで一覧に出ます。 同じ名前が下の場所にあれば、そちらが先)。サムネイルは、ゲームの中に入っているので、動画だけで足ります。
  - ラズパイの `~/mjdata/video/`
  - SDカードの boot の区画(Windows/Macから見えるところ)の `mjdata/video/` か `mjdata/` 直下(`/boot/firmware/mjdata` または `/boot/mjdata`)名前は「`01_10分で分かる麻雀ルール.mp4`」と「`01_10分で分かる麻雀ルール.png`」のように、番号_題名を同じにします。
- 4番に「リーチされたら、この順番で切る」を入れたので、前の4番〜16番は、5番〜17番になりました。 SDカードの動画(と .png)の名前の番号も、4番以降を1つずつ後ろにずらしてください: `tools/video/shift_numbers.sh`(Mac/Linux)か `shift_numbers.ps1`(Windows)を、動画のフォルダで実行します。 そのあと、新しい `04_xxx.mp4` を入れます。 見た記録(つづきから)は、ゲームが自動で番号を1つ進めて引きつぎます。
- ゲームの「勉強」→ 4ページ目「ビデオ」から見ます。動画を増やすと、一覧に自動で出ます。
- 操作: ◀ 10秒もどす(長押しで30秒ずつ) / ▶ 10秒すすむ(長押しで30秒ずつ) / 決定(A) 一時停止・再生 / 戻る(B) やめる。止めた位置は覚えていて、「つづきから」で続きが見られます。
- ビルドに FFmpeg の開発ファイルが要ります: `sudo apt install libavcodec-dev libavformat-dev libswscale-dev libswresample-dev libavutil-dev`(無いときは動画なしでビルドされます)。
- この機械で間に合うかの確認: `./mj .. --vtest 動画.mp4`(「実時間の1倍以上ならOK」)。ふだんは、まずハードウェア解読(h264_v4l2m2m)を試し、使えなければ自動でふつうの解読にします。ふつうの解読に固定するには `MJ_VDEC=h264 ./start.sh`。映像と音のずれは `MJ_AVOFF=ミリ秒` で調整できます(例: `MJ_AVOFF=-80`)。
- 間に合わないときは、自動で画質を少し落として(ループフィルタ省略)コマ落ちを減らします。

## 画面の見た目を前に戻す(環境変数)
- `MJ_LEARN=old ./start.sh`: 点数計算の勉強を、前の(タブで切りかえる)見た目に戻します。麻雀の勉強の入口は、ホームから入る新しい画面のままです。
- `MJ_STYLE=old`: 浮世絵版の前の絵に戻します。
- 麻雀の勉強の入口を作る前の状態は、git のタグ `pre-study-b` で戻せます。

## 動きが止まる(カクつく・BGMが切れる)ときの調べ方
- 重い処理で 0.15秒以上止まると、`~/mjdata/stall.log` に、時刻・止まった時間・そのときの画面の状態が書かれます(`MJ_STALL=ミリ秒` で基準を変更。`0` で書かない)。
- ゲーム本体の優先度は、少し下げてあります(BGMの音が先に動くため)。変えるときは `MJ_NICE=数字`(`0` で下げない)。

## 動画を、ラズパイで らくに再生できる形に作り直す
- ラズパイ Zero W は、動画の解読が重いので、動画を軽い形(15コマ/秒・解読しやすい設定・音は軽いAAC)に作り直します。解読の負荷が、およそ4分の1になります。
- PC で `tools/video/lighten.bat`(Windows)か `lighten.sh`(Mac/Linux)を、動画のフォルダで実行します。`light` フォルダに、できあがりが入ります。FFmpeg が必要です。
- 速さの確認: `./mj ../.. --vtest 動画.mp4`(「実時間の1倍」ではぎりぎり。2〜3倍以上が目安)
