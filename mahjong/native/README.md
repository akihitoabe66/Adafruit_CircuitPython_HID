
## セーブ・メニュー(Pi版)
- 局が終わるたび「セーブして次の局へ / セーブしないで次の局へ」(手動のみ。オートセーブなし)。
- セーブは `~/mjdata/save_<連番>.json`(環境変数 MJ_DATA で変更可)。最新5件を保持。別名で書いてから名前を変えるので、電源断でも前のものは壊れない。
- タイトルの「つづきから」=最新のセーブ。隠しコマンド(タイトルで 上 上 下 下 左 右)=5件から選んでロード(ロードすると一覧は消える)。
- スタート+セレクトを1.2秒長押し=メニュー(つづける / ホームにもどる / おわる)。Ctrl+Q でも終了。

## CPUの速さ(Pi版)
- タイトルの「CPUの速さ: ふつう/高速/思考」を決定ボタンで切り替え(メニュー(スタート+セレクト長押し)にもあり。保存される)。
- デバッグ用: `MJ_CPU=fast ./native/app/mj .`(起動時に指定)。
- Pi版ではCPUの思考の時間上限を0.4倍に縮めてある(`MJ.AI_BUDGET`)。考えている間は画面・入力が止まるため。
