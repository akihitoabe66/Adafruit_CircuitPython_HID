## 冷却ファン(GPIO17)を、ゲームが動いている間だけ回す
- 入れかた(ラズパイで、git pull のあと): `sudo sh ~/Adafruit_CircuitPython_HID/mahjong/native/pi/install_led.sh --fan-game`(場所は、あなたの checkout に合わせる)。 そのあと `sudo reboot`。 CPU温度で回す従来の方式は `--fan`。
- 動き: 麻雀(mj)が動いている間は 回り、終わると1秒ほどで止まる。 動いていなくても CPU が 70度以上なら 回す(安全)。
- つなぎかた: GPIO17 の電流は 少ししか流せない(目安 16mA 以下)。 ファンは「5Vのピン → ファン → トランジスタ/MOSFETのスイッチ基板 ← GPIO17」で つなぐこと。 GPIO17 に ファンを直接つなぐと、電流が足りず回らないか、Pi が傷む。
- 確認: ゲーム起動で回り始めるか / 終了(Ctrl+Q・電源オフ)で止まるか。 `systemctl status mjled` と `journalctl -u mjled` で状態が見られる。
