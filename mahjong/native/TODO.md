## Wii/NESクラシックのコントローラー(GPIOのI2C)を、ゲームパッドとして使う(実機で確認)
- つなぎかた: 3.3V=物理1番 / SDA=物理3番(GPIO2) / SCL=物理5番(GPIO3) / GND=物理6番。 コントローラーは I2C のアドレス 0x52。

## 声の並び(結果画面の読み上げ)が途中で切れる → 音の側の時計で予約(実機で確認。 C を変えたので 作りなおしが必要)
- 原因: 声の並び(名前・ロン・役・点数…の細かい声)を、1つずつ JS のタイマーで鳴らしていた。 JSのタイマーは 画面を描き終わってからしか動かない → 結果画面は 1回描くのに 0.2〜0.3秒かかるので、声と声の間が その分ずつ あく(途切れて聞こえる)。
- 直した: 声の時刻を、まとめて音の側(別スレッドの時計 / main.c の snd.playAt)に予約する。 描きが重くても 間があかない(パソコンで JS を 0.9秒 止めても、遅れは 10ms以内)。 メニューを開いている間は、時計も止まる。 スキップ(決定)・次の声で、予約はやめる(snd.cancelAt)。
- 実機: `cd ~/Adafruit_CircuitPython_HID/mahjong/native/app && sh build.sh`(数分)→ 再起動。 確認: 結果画面の読み上げが 最後まで つながるか。 局の名前(トン・二局)・流局の読み上げ・クイズの声も。
